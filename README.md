# Медстат на R

Курс и тренажёр медицинской статистики в R для врачей и исследователей в психиатрии, без программирования.
Код для своих данных вы получаете от Claude, а сайт учит понимать методы и правильно читать результаты.

## Что внутри

- **18 модулей** — от установки R до описания статистики в статье: типы данных, описательная статистика, графики,
  p-value и доверительные интервалы, размеры эффекта (RR, OR, NNT), сравнение групп, ANOVA, χ² и Фишер,
  корреляция, линейная и логистическая регрессия, смешанные модели и пропуски, анализ выживаемости,
  диагностические тесты и ROC, надёжность шкал (α, ICC, каппа), размер выборки, руководства CONSORT/STROBE/STARD.
- **Тренажёр** — 87 вопросов: выбор метода, чтение вывода R, поиск ошибок, расчёты. Есть «Работа над ошибками» и итоговый экзамен.
- **Помощник «Какой метод выбрать?»** — несколько вопросов о данных, в конце метод, шаблон кода R и запрос для Claude.
- **Симуляторы** — p-value и мощность, доверительные интервалы, чувствительность/специфичность/PPV, калькулятор RR/OR/NNT, корреляция.
- **Шаблоны запросов для Claude** и словарь терминов (рус./англ.).

Прогресс сохраняется в браузере (localStorage).

## Как открыть

Откройте `index.html` в браузере: двойной щелчок, сервер не нужен. Можно включить GitHub Pages для этого репозитория.

Один самодостаточный файл со всем внутри собирается так: `python3 tools/build_single.py medstat.html`.

## Данные и примеры

Все данные **вымышленные**: они смоделированы скриптом `data/make_datasets.R`. Это не реальные пациенты и не реальный препарат.
Весь вывод R на сайте получен настоящим запуском `analysis/run_examples.R` (R 4.3.3), рисунки построены скриптом `analysis/make_plots.R`.

```
cd data
Rscript make_datasets.R
Rscript ../analysis/run_examples.R > ../analysis/outputs.txt
```
